# Pollard Finance and Education – social media files
Public images and videos for Instagram and Facebook posts, read by Metricool when posts are scheduled. Kept separate from the app so posting doesn't use the app's hosting.
- `<YYYY-MM-DD>/` – files for the week starting that Monday.
- `_template-9x16/` – the Stories and Reels template and scripts (see its README).
